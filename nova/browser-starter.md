This file is retired. Do not read it as instructions.

It was the original browser Nova, and `nova/install-only.md` is the version
that is maintained. The two were near-duplicates of the same behaviour rules,
they drifted apart within a single day, and the birth side of the product spent
that day running the stale copy while every fix landed in the other one.

There is one Nova now, and one place its behaviour is written:

- **`nova/install-only.md`** holds how Nova behaves, sounds, opens, and closes,
  plus the job of getting Claude Code installed. Both Novas read it.
- **The setup protocol in this repo's README** holds the other job, birthing the
  agent, and points at that same file for behaviour.

If you arrived here from an older link, go to `nova/install-only.md`.
